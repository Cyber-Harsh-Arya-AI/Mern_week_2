## 📌 Overview

Week 2 focused on Backend Development as part of my Full Stack Web Development (MERN) learning journey.

The primary objective was to understand how backend applications work, build RESTful APIs, integrate databases, implement authentication, and understand how frontend and backend communicate in a full-stack application.

Alongside the weekly curriculum, I studied a comprehensive MERN Stack tutorial by Dave Gray to strengthen my understanding of real-world full-stack application development.

## 🛠️ Technologies & Concepts Covered

- **Node.js:** JavaScript runtime environment for backend development.
- **Express.js:** Backend framework for building APIs and handling routes.
- **MongoDB:** NoSQL database for storing application data.
- **Mongoose:** Object Data Modeling (ODM) for MongoDB.
- **REST APIs:** Designing endpoints and handling HTTP requests.
- **JWT:** Token-based authentication and authorization.
- **bcrypt:** Secure password hashing.
- **Postman:** API testing and debugging.
- **React.js:** Building interactive frontend applications.
- **Redux Toolkit & RTK Query:** State management and API data fetching.
